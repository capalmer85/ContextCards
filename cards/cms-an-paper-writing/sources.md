# Sources

List of source materials used to build context.md, and what each contributed.

- [CMS Guidelines for Authors](https://twiki.cern.ch/twiki/bin/view/CMS/Internal/PubGuidelines) — style and format rules for CMS papers/ANs: language/spelling, grammar/punctuation, numbers, acronyms, symbols/units/particle names, word usage/jargon, title/abstract/figures/references/supplemental material. CERN SSO-protected. Looked up: 2026-07-28.
- [CMS Supplementary Material Instructions](https://cms-results.web.cern.ch/cms-results/public-results/temp/AdditionalMaterial.html) — process for adding approved supplementary figures/tables/data files to CMS public results web pages. Public (no auth). Looked up: 2026-07-28.
- [CMS Detector Description (PubDetector)](https://twiki.cern.ch/twiki/bin/viewauth/CMS/Internal/PubDetector) — standard copy-paste LaTeX boilerplate for detector-description and physics-object-reconstruction sections of CMS papers (short/long detector paragraphs, trigger, primary vertex, particle-flow, jets, MET, Combine citation, luminosity, standard reference list). CERN SSO-protected. Only the most broadly-applicable paragraphs were pulled; page has many more situational variants not reproduced verbatim. Note: the static attached PDF on this page (CMS_Internal_PubDetector.pdf) is a stale 2014 version that contradicts current guidance — the live page (and its on-demand generated PDF) was used instead. Looked up: 2026-07-28.
- [CMS Figure Guidelines (FigGuidelines)](https://twiki.cern.ch/twiki/bin/view/CMS/Internal/FigGuidelines) — figure/plot conventions: CMS label placement and wording by purpose, fonts, legends, data points/error bars, color palette pointer, 3D plot color conventions, Brazilian flag plot convention (older hex codes — see discrepancy note in context.md). CERN SSO-protected. Looked up: 2026-07-28.
- [CMS Analysis Docs: Plotting Guidelines](https://cms-analysis.docs.cern.ch/guidelines/plotting/) and linked sub-pages [general/](https://cms-analysis.docs.cern.ch/guidelines/plotting/general/), [colors/](https://cms-analysis.docs.cern.ch/guidelines/plotting/colors/), [fonts/](https://cms-analysis.docs.cern.ch/guidelines/plotting/fonts/) — current/actively-maintained plotting styling reference (fonts, CMS label positioning/rules, color schemes for categorical/sequential/diverging data and Brazilian flag plots, with Python/mplhep and ROOT/cmsstyle code examples). Loaded without an SSO prompt in this session (may still require CERN auth in general). Looked up: 2026-07-28.
- [jsetools (GitLab)](https://gitlab.cern.ch/joknolle/jsetools) — repository of BibTeX entries for CMS publications (formatted per CMS style guidelines) plus scripts for maintaining/exporting a paper's reference list. Maintained by Joscha Knolle. Looked up: 2026-07-28.
- [Paper Submission Prep (PaperSubmissionPrep)](https://twiki.cern.ch/twiki/bin/viewauth/CMS/Internal/PaperSubmissionPrep) — step-by-step checklist for preparing a paper for submission (common ReadyForSub issues, macro/penname usage, table formatting, references, journal-specific compile commands, figure/table placement, equation splitting across columns). CERN SSO-protected. Extracted verbatim via page text. Looked up: 2026-07-28.
- [Paper Submission Format (PaperSubmissionFormat)](https://twiki.cern.ch/twiki/bin/view/CMS/Internal/PaperSubmissionFormat) — detailed LaTeX formatting conventions: equation/spacing rules, en/em dash usage, LaTeX2e vs TeX syntax, standard macros and pennames (with before/after examples), units, figure/table/appendix formatting. CERN SSO-protected. Extracted verbatim via page text. Looked up: 2026-07-28.
